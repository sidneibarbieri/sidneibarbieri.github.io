# Synthetic policy walkthrough

The illustrated walkthrough is generated from the output of the SOCpilot
`policy_example` module. The source tool is MIT-licensed; see the policy-verifier
LICENSE. Frames are rendered by `render_synthetic_demo.py`; narration is generated
locally with the macOS Daniel voice. No third-party footage or music is included.

Input is a source-defined synthetic example with empty telemetry. The video shows
the actual plan checks and repairs as large illustrated cards. No operational
incident data, model calls or response actions are used.

The recording is a read-only explanation of the CLI report. It does not demonstrate
an interactive response console or measure incident containment.
